# Get All Decision Rules

**Endpoint**: `GET /api/business-rules`

Retrieves all decision rules, including every version of each rule. The list is ordered by name, then by version.

## Response

* Returns 200 OK with a list of all versions of the decision rules you have access to. Each entry includes its name, version, decision table in CSV format, create and update times in epoch milliseconds, the users who created and last updated it, and its tags. Users with the Admin, Metadata Manager, or Business Rule Manager role see all decision rules. Other users see only the decision rules they have READ access to.
* Returns 401 Unauthorized if the token is missing or invalid.

The response includes the full decision table of every version, so it can be large when you have many rules or large tables. To retrieve a single rule, use [Get Latest Version of Decision Rule](/content/reference-docs/api/business-rules/get-latest-version-of-decision-rule) or [Get All Versions of Decision Rule](/content/reference-docs/api/business-rules/get-all-versions-of-decision-rule).

  -H 'X-Authorization: <TOKEN>'
