# Get All Versions of Decision Rule

**Endpoint**: `GET /api/business-rules/{name}/versions`

Retrieves all versions of a decision rule by its name, with the newest version first.

## Path parameters

| Parameter | Description | Type | Required/ Optional |
| --------- | ----------- | ---- | ------------------ |
| name | The name of the decision rule to retrieve. | string | Required. |

## Response

* Returns 200 OK with a list of all versions of the decision rule, newest first. Each version includes its name, version, decision table in CSV format, create and update times in epoch milliseconds, and the users who created and last updated it.
* Returns 403 Forbidden if you do not have access to the decision rule.
* Returns 401 Unauthorized if the token is missing or invalid.

  -H 'accept: application/json' \
  -H 'X-Authorization: <TOKEN>'
