# Get Auth Config for Gateway

**Endpoint**: `GET /api/gateway/config/auth/{id}`

Retrieves the details of a specific auth config.

## Path parameters

| Parameter | Description | Type | Required/ Optional |
| --------- | ------------ | ---- | ------------------- |
| id | The id of the auth config to retrieve. | string | Required. |

## Response

* Returns a `200 OK` response with auth config details, including its application ID associated with, and the authentication metadata. For auth configs that use API keys, the `apiKeys` field returns each key masked as `***`. The actual key values are never returned.
* Returns 404 Not Found if no auth config exists with the given `id`.
* Returns 403 Forbidden if you do not have access to the auth config.

## Examples

<details markdown="1">
<summary>Get auth config for Gateway</summary>

**Request**

```shell
curl -X 'GET' \
  'https://<YOUR-SERVER-URL>/api/gateway/config/auth/gateway' \
  -H 'accept: application/json' \
  -H 'X-Authorization: <TOKEN>'
```

**Response**

```json
{
  "id": "gateway",
  "authenticationType": "NONE",
  "passthrough": false,
  "fallbackToDefaultAuth": false,
  "tokenInWorkflowInput": false,
  "applicationId": "643cc628-5a73-47bd-8a0c-7d6d58da4fdd",
  "createdBy": "john.doe@acme.com",
  "updatedBy": "john.doe@acme.com",
  "orgId": "fd7s"
}
```
