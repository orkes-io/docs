# Get Gateway Service

**Endpoint**: `GET /api/gateway/config/services/{serviceId}`

Retrieves the details of a specific gateway service.

## Path parameters

| Parameter | Description | Type | Required/ Optional |
| --------- | ------------ | ---- | ------------------- |
| serviceId | The service ID of the gateway service to retrieve. You can get the service ID from the `id` field of the [Get All Gateway Service’s output](/reference-docs/api/gateway/get-all-gateway-service). | string | Required. |

## Response

Returns a 200 OK response with service details, including its id, name, path, and route metadata.

## Examples

```shell

  -H 'accept: application/json' \
  -H 'X-Authorization: <TOKEN>'
```
