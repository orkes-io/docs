# GitHub Integration with Orkes Conductor

:::info Available since
- v5.7.0 and later
:::

Integrating GitHub with Orkes Conductor lets you build workflows that interact with your GitHub repositories by managing issues, pull requests, branches, files, releases, workflows, and more. The integration authenticates as a GitHub App.

This guide explains how to set up and use the integration. Here’s an overview:

1. Create a GitHub App and get its credentials.
2. Configure a new GitHub integration in Orkes Conductor.
3. Use GitHub integration in workflows.

## Step 1: Get the GitHub credentials

To integrate GitHub with Orkes Conductor, create a GitHub App, install it on your account or organization, and collect three values: the App ID, the Installation ID, and a private key. Installation tokens are generated automatically from these.

**To create the app:**

1. Sign in to [GitHub](https://github.com/) and go to **Settings** > **Developer settings** > **GitHub Apps**.
2. Select **New GitHub App**, enter a name and a homepage URL, and uncheck the **Webhook Active** option.
3. Set the following permissions for the operations you plan to use:
    1. **Repository permissions**:
        1. **Contents**: *Read and write*
        2. **Issues**: *Read and write*
        3. **Pull requests**: *Read and write*
        4. **Actions**: *Read and write*
        5. **Workflows**: *Read and write*
        6. **Administration**: *Read and write*
    2. **Organization permissions**:
        1. **Members**: *Read-only*
4. Select **Create GitHub App**. The **App ID** is shown at the top of the app's General page.
5. On the **Credentials** page, open the **Key pairs** tab and select **New key**. A .pem file downloads. This is the private key.
6. To install the app on an organization, open your app from **Settings** > **Developer settings** > **GitHub Apps**, go to the **Advanced** page, and select **Make public** under "Make this GitHub App public". By default, an app can be installed only on the account that owns it.
7. Select **Install App**, choose your account or organization, and select the repositories the app can access.
8. After the installation, the number at the end of the installation settings URL (.../installations/&lt;number&gt;) is the **Installation ID**.

If you change the app's permissions later, accept the updated permissions on the installation before using them.

## Step 2: Add an integration for GitHub

After obtaining the credentials, add a GitHub integration to your Conductor cluster.

**To create an integration:**

<ol>
<li>Go to <strong>Integrations</strong> &gt; <strong>Connected Apps</strong> from the left navigation menu on your Conductor cluster.</li>
<li>Select <strong>+ New integration</strong>.</li>
<li>In the <strong>Source Control</strong> section, choose <strong>GitHub</strong>.</li>
<li>Select <strong>+ Add</strong> and enter the following parameters:</li>
</ol>

| Parameter | Description | Required/Optional |
| --------- | ----------- | ----------------- |
| Integration name | A name for the integration. | Required. | 
| App ID | The GitHub App ID from [Step 1](/content/integrations/github#step-1-get-the-github-credentials), shown at the top of the app's General page. | Required. |
| Installation ID | The ID of the app's installation in the target organization or account from [Step 1](/content/integrations/github#step-1-get-the-github-credentials), which is the number at the end of the installation settings URL. | Required. |
| Private Key | The GitHub App RSA private key in PEM format (PKCS#1 or PKCS#8). Open the downloaded .pem file and paste its full contents, including the BEGIN and END lines. Installation tokens are generated automatically. | Required. |
| API Base URL | The GitHub API base URL. Defaults to https://api.github.com. | Optional. |
| Description | A description of the integration. | Required. | 

<ol start="5">
<li>(Optional) Toggle the <strong>Active</strong> button off if you don't want to activate the integration instantly.</li>
<li>Select <strong>Save</strong>.</li>
</ol>

The integration is created successfully.

## Step 3: Use GitHub integration in workflows

Once the integration is ready, this can be used directly within the workflows. 

**To use GitHub integration in a workflow:**

<ol>
<li>Go to <strong>Definitions</strong> &gt; <strong>Workflow</strong> from the left navigation menu on your Conductor cluster.</li>
<li>Select <strong>+ Define workflow</strong>.</li>
<li>In your workflow, select the (<strong>+</strong>) icon and select <strong>Connected Apps</strong>.</li>
<li>In <strong>Add Task</strong> panel on the right, search for <strong>GitHub</strong>, and select the integration created in <a href="/content/integrations/github#step-2-add-an-integration-for-github">Step 2</a>.</li>
</ol>
