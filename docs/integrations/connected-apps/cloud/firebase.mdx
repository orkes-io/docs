# Firebase Cloud Functions Integration with Orkes Conductor

:::info Available since:
- v5.7.0 and later
:::

Integrating Firebase Cloud Functions with Orkes Conductor lets you build workflows that deploy, manage, and invoke your Firebase functions using the following operations:

- List Functions
- Get Function Details
- Create Function
- Update Function Configuration
- Get Deployment Status
- Delete Function
- Invoke HTTP Function
- Invoke Callable Function

This guide explains how to set up and use the integration. Here's an overview:

1. Get the required credentials from Google Cloud Console.
2. Configure a new Firebase Cloud Functions integration in Orkes Conductor.
3. Use Firebase Cloud Functions integration in workflows.

## Step 1: Get the Google Cloud credentials

The credentials you need depend on the function type and authentication you choose.

| Function type | Authentication | Credentials you need |
| ------------- | -------------- | -------------------- |
| HTTP | None | Management service account key. |
| HTTP | Google ID token | Management service account key and HTTP invocation service account key. |
| Callable | App Check: Disabled | Management service account key. |
| Callable | App Check: Service Account | Management service account key, Firebase App ID, and App Check service account key. |

### Management service account key

*For Management Google Credentials (JSON).*

1. Go to the [Google Cloud Console](https://console.cloud.google.com/) and select your Firebase project.
2. Navigate to **IAM & Admin** > **Service Accounts**.
3. Select **+ Create service account**, enter a name and description, and select **Create and continue**.
4. Assign the IAM roles required to manage Cloud Functions, then select **Continue** and **Done**.
5. Select the new service account, go to the **Keys** tab, and select **Add Key** > **Create new key**.
6. Choose **JSON** as the key type and select **Create**. The key file downloads automatically.

Enable these APIs for the project (**APIs & Services** > **Enabled APIs & services** > **+ Enable APIs and services**): **Cloud Functions API**, **Cloud Build API**, **Cloud Run Admin API**, and **Artifact Registry API**. Cloud Build requires a project with billing.

### HTTP invocation service account key

*For HTTP Invocation Google Credentials (JSON). Only for the Google ID token option.*

1. Create a service account, or select an existing one, in **IAM & Admin** > **Service Accounts**.
2. Grant it permission to invoke your function: **Cloud Run Invoker** on the function's Cloud Run service for 2nd gen functions.
3. Create a **JSON** key for it, as in steps 5–6 above.

### App Check credentials

*For Firebase App ID and App Check Google Credentials (JSON). Only for the Service Account option.*

1. In the Firebase Console, go to **Project settings** > **General** > **Your apps** and register a web app. Copy its **App ID**, for example `1:123456789:web:abcdef`.
2. Enable the **Firebase App Check API** for the project.
3. In **IAM & Admin** > **Service Accounts** of the same project, select or create a service account and grant it **Firebase App Check Admin**.
4. Create a **JSON** key for that service account, as in steps 5–6 above.

### Finding the function URL

*For [Invoke HTTP Function](/content/integrations/firebase-operations#invoke-http-function) and [Invoke Callable Function](/content/integrations/firebase-operations#invoke-callable-function).*

You enter the function's HTTPS URL in these two operations. It must be `.cloudfunctions.net` or `.run.app` and have no query parameters or fragment.

1. Go to the [Firebase Console](https://console.firebase.google.com/) and select your project.
2. Go to **Hosting & Serverless** > **Functions** and select the function.
3. Copy its HTTPS trigger URL.

For a function created with the Create Function operation, use the `url` field of the **Get Function Details** output, or `functionUrl` of **Get Deployment Status** once the function is `READY`.

## Step 2: Add an integration for Firebase Cloud Functions

After obtaining the credentials, add a Firebase Cloud Functions integration to your Conductor cluster.

**To create an integration:**

<ol>
<li>Go to <strong>Integrations</strong> &gt; <strong>Connected Apps</strong> from the left navigation menu on your Conductor cluster.</li>
<li>Select <strong>+ New integration</strong>.</li>
<li>In the <strong>Cloud</strong> section, choose <strong>Firebase Cloud Functions</strong>.</li>
<li>Select <strong>+ Add</strong> and enter the following parameters:</li>
</ol>

| Parameter | Description | Required/Optional |
| --------- | ----------- | ----------------- |
| Integration name | A name for the integration. | Required. |
| Function type | The type of function to invoke. Supported types:<ul><li>**HTTP** uses Invoke HTTP Function.</li><li>**Callable** uses Invoke Callable Function.</li></ul> | Required. |
| Management Google Credentials (JSON) | The full contents of the service account key JSON from [Step 1](/content/integrations/firebase#management-service-account-key). Used by the management operations, independent of invocation authentication. | Required. |
| HTTP Authentication | The type of authentication for HTTP functions. Supported types:<ul><li>**None** sends no identity token.</li><li>**Google ID token** gets a fresh, audience-specific token for each invocation.</li></ul> | Required if *Function Type* is *HTTP*. |
| HTTP Invocation Google Credentials (JSON) | The service account key JSON from [Step 1](/content/integrations/firebase#http-invocation-service-account-key), used to get Google ID tokens. | Required if *HTTP Authentication* is *Google ID token*. |
| App Check | The App Check setting for callable functions. Supported types:<ul><li>**Disabled** sends no App Check token.</li><li>**Service Account** gets an App Check token for each invocation.</li></ul> | Required if *Function Type* is *Callable*. |
| Firebase App ID | The registered Firebase app ID from [Step 1](/content/integrations/firebase#app-check-credentials), for example `1:123456789:web:abcdef`. | Required if *App Check* is *Service Account*. |
| App Check Google Credentials (JSON) | The service account key JSON from [Step 1](/content/integrations/firebase#app-check-credentials), authorized to mint App Check tokens. | Required if *App Check* is *Service Account*. |
| App Check Token Type | The type of App Check token to send. Supported types:<ul><li>**Session**</li><li>**Limited Use (Replay Protection)** for callable functions that enforce replay protection.</li></ul> | Required if *App Check* is *Service Account*. |
| Description | A description of the integration. | Required. |

<ol start="5">
<li>(Optional) Toggle the <strong>Active</strong> button off if you don't want to activate the integration instantly.</li>
<li>Select <strong>Save</strong>.</li>
</ol>

The integration is created successfully.

## Step 3: Use Firebase Cloud Functions integration in workflows

Once the integration is ready, this can be used directly within the workflows.

**To use Firebase Cloud Functions integration in a workflow:**

<ol>
<li>Go to <strong>Definitions</strong> &gt; <strong>Workflow</strong> from the left navigation menu on your Conductor cluster.</li>
<li>Select <strong>+ Define workflow</strong>.</li>
<li>In your workflow, select the (<strong>+</strong>) icon and select <strong>Connected Apps</strong>.</li>
<li>In <strong>Add Task</strong> panel on the right, search for <strong>Firebase Cloud Functions</strong>, and select the integration created in <a href="/content/integrations/firebase#step-2-add-an-integration-for-firebase-cloud-functions">Step 2</a>.</li>
</ol>

The following operations are available for use with this integration.

| Operation | Description |
| --------- | ----------- |
| [List Functions](/content/integrations/firebase-operations#list-functions) | Lists the Cloud Functions in a Firebase project and region. |
| [Get Function Details](/content/integrations/firebase-operations#get-function-details) | Gets the deployed configuration and metadata of a function. |
| [Create Function](/content/integrations/firebase-operations#create-function) | Creates a 2nd gen HTTP or callable function from a ZIP source. |
| [Update Function Configuration](/content/integrations/firebase-operations#update-function-configuration) | Updates a function's runtime configuration without changing its source. |
| [Get Deployment Status](/content/integrations/firebase-operations#get-deployment-status) | Reads the status of a create, update, or delete operation. |
| [Delete Function](/content/integrations/firebase-operations#delete-function) | Deletes a function and its managed resources. |
| [Invoke HTTP Function](/content/integrations/firebase-operations#invoke-http-function) | Invokes an HTTP function with an optional JSON body. Available when Function type is HTTP. |
| [Invoke Callable Function](/content/integrations/firebase-operations#invoke-callable-function) | Invokes a callable function. Available when Function type is Callable. |

<ol start="5">
<li>Select the required operation, configure the parameters, and select <strong>Save</strong> &gt; <strong>Confirm</strong>.</li>
<li>Select <strong>Execute</strong> to run the workflow.</li>
</ol>

For the complete operations parameters and output reference, see [Firebase Cloud Functions Operations Reference](/content/integrations/firebase-operations).
