# AWS S3 Operations Reference

Orkes Conductor integrates with AWS S3 to let you create and manage buckets, objects, and folders directly from your workflows. Once you configure the AWS S3 integration, you can use the following operations to create, retrieve, upload, and delete data in AWS S3 without leaving your workflow.

This page covers the parameters and expected output for each operation available in the [AWS S3 integration](/content/integrations/aws-s3).

## Create Bucket

Creates a new S3 bucket.

<Tabs>
<TabItem value="input" label="Input Parameters">

| Parameter | Description | Type | Required/Optional |
| --------- | ----------- | ---- | ----------------- |
| Region | The AWS region to create the bucket in. For example: `us-east-1`. | string | Required. |
| Service Endpoint | A custom service endpoint, when required. | string | Optional. |
| Bucket Name | The name of the bucket to create. Must be unique across all accounts globally, i.e., no two buckets anywhere can share the same name. | string | Required. |

</TabItem>
<TabItem value="output" label="Output Parameters">

Returns the `status`, `bucketName`, and `location` of the created bucket.

</TabItem>
</Tabs>

## List Buckets

Lists all S3 buckets in the AWS account.

<Tabs>
<TabItem value="input" label="Input Parameters">

| Parameter | Description | Type | Required/Optional |
| --------- | ----------- | ---- | ----------------- |
| Region | The AWS region the operation runs in. For example: `us-east-1`. | string | Required. |
| Service Endpoint | A custom service endpoint, when required. | string | Optional. |

</TabItem>
<TabItem value="output" label="Output Parameters">

Returns a `buckets` array, where each entry includes the bucket `name` and `creationDate`.

</TabItem>
</Tabs>

## Search Buckets

Searches for S3 buckets by partial name match. The match is not case-sensitive.

<Tabs>
<TabItem value="input" label="Input Parameters">

| Parameter | Description | Type | Required/Optional |
| --------- | ----------- | ---- | ----------------- |
| Region | The AWS region the operation runs in. For example: `us-east-1`. | string | Required. |
| Service Endpoint | A custom service endpoint, when required. | string | Optional. |
| Search Pattern | The partial bucket name to search for. Returns all buckets if not specified. | string | Optional. |

</TabItem>
<TabItem value="output" label="Output Parameters">

Returns a `buckets` array, where each entry includes the bucket `name` and `creationDate`, along with a `count` of the total matching buckets.

</TabItem>
</Tabs>

## Delete Bucket

Deletes an empty S3 bucket.

<Tabs>
<TabItem value="input" label="Input Parameters">

| Parameter | Description | Type | Required/Optional |
| --------- | ----------- | ---- | ----------------- |
| Region | The AWS region containing the bucket. | string | Required. |
| Service Endpoint | A custom service endpoint, when required. | string | Optional. |
| Bucket Name | The name of the bucket to delete. | string | Required. |

</TabItem>
<TabItem value="output" label="Output Parameters">

Returns the `status` of the deletion and the `bucketName` of the deleted bucket.

</TabItem>
</Tabs>

## Upload Object

Uploads content as an S3 object to a specified bucket. If the key already exists, the object is replaced.

<Tabs>
<TabItem value="input" label="Input Parameters">

| Parameter | Description | Type | Required/Optional |
| --------- | ----------- | ---- | ----------------- |
| Region | The AWS region containing the bucket. | string | Required. |
| Service Endpoint | A custom service endpoint, when required. | string | Optional. |
| Bucket Name | The name of the bucket to upload the object to. | string | Required. |
| Key | The object key (filename or path) of the object in S3. For nested objects, include the full path. For example, `folder/file.txt`. | string | Required. |
| Content | The file content to upload as a string. | string | Required. |
| Content Type | The MIME type of the object. For example, `text/plain` or `application/json`. | string | Optional. |

</TabItem>
<TabItem value="output" label="Output Parameters">

Returns the `status` of the upload, the `bucket` name, the object `key`, and the `size` of the uploaded object in bytes.

</TabItem>
</Tabs>

## List Objects

Lists objects in an S3 bucket, optionally filtered by prefix.

<Tabs>
<TabItem value="input" label="Input Parameters">

| Parameter | Description | Type | Required/Optional |
| --------- | ----------- | ---- | ----------------- |
| Region | The AWS region containing the bucket. | string | Required. |
| Service Endpoint | A custom service endpoint, when required. | string | Optional. |
| Bucket Name | The name of the bucket to list objects from. | string | Required. |
| Prefix | The prefix to filter objects by. For example, `documents/`. | string | Optional. |
| Max Keys | The maximum number of objects to return. Defaults to 1000. | integer | Optional. |

</TabItem>
<TabItem value="output" label="Output Parameters">

Returns an `objects` array, where each entry includes the object `key`, `size` in bytes, `etag`, and `lastModified` timestamp. Also returns `isTruncated`, which is true when more objects exist, and `nextContinuationToken`. This operation has no input to continue from the token.

</TabItem>
</Tabs>

## Download Object

Downloads an S3 object and returns its content as a string.

<Tabs>
<TabItem value="input" label="Input Parameters">

| Parameter | Description | Type | Required/Optional |
| --------- | ----------- | ---- | ----------------- |
| Region | The AWS region containing the bucket. | string | Required. |
| Service Endpoint | A custom service endpoint, when required. | string | Optional. |
| Bucket Name | The name of the bucket containing the object. | string | Required. |
| Key | The object key (filename or path) of the object in S3. For nested objects, include the full path. For example, `folder/file.txt`. | string | Required. |

</TabItem>
<TabItem value="output" label="Output Parameters">

Returns the `status` of the download, the `bucket` name, the object `key`, the `content` of the object as a string, the `size` in bytes, and a `message`.

If the object does not exist, it returns `status` as `error` and `message` as `Object not found`, and the task ends as completed with errors.

</TabItem>
</Tabs>

## Get Object Metadata

Retrieves metadata about an S3 object, including size, last modified date, and content type.

<Tabs>
<TabItem value="input" label="Input Parameters">

| Parameter | Description | Type | Required/Optional |
| --------- | ----------- | ---- | ----------------- |
| Region | The AWS region containing the bucket. | string | Required. |
| Service Endpoint | A custom service endpoint, when required. | string | Optional. |
| Bucket Name | The name of the bucket containing the object. | string | Required. |
| Key | The object key (filename or path) of the object in S3. For nested objects, include the full path. For example, `folder/file.txt`. | string | Required. |

</TabItem>
<TabItem value="output" label="Output Parameters">

Returns the `bucket` name, object `key`, `size` in bytes, `lastModified` timestamp, `contentType`, `etag`, `userMetadata`, `status`, and a `message`.

If the object does not exist, it returns `status` as `error` and `message` as `Object not found`, and the task ends as completed with errors.

</TabItem>
</Tabs>

## Copy Object

Copies an S3 object to a destination bucket.

<Tabs>
<TabItem value="input" label="Input Parameters">

| Parameter | Description | Type | Required/Optional |
| --------- | ----------- | ---- | ----------------- |
| Region | The AWS region containing the destination bucket. | string | Required. |
| Service Endpoint | A custom service endpoint, when required. | string | Optional. |
| Source Bucket | The name of the source bucket. | string | Required. |
| Source Key | The object key (filename or path) of the source object. For nested objects, include the full path. For example, `folder/file.txt`. | string | Required. |
| Destination Bucket | The name of the destination bucket. | string | Required. |
| Destination Key | The object key (filename or path) for the copied object in the destination bucket. For nested objects, include the full path. For example, `folder/file.txt`. | string | Required. |

</TabItem>
<TabItem value="output" label="Output Parameters">

Returns the `status` of the copy, the `sourceBucket`, `sourceKey`, `destinationBucket`, `destinationKey`, and the `etag` of the copied object.

</TabItem>
</Tabs>

## Delete Object

Deletes an object from an S3 bucket. If the key does not exist, it still returns `success`.

<Tabs>
<TabItem value="input" label="Input Parameters">

| Parameter | Description | Type | Required/Optional |
| --------- | ----------- | ---- | ----------------- |
| Region | The AWS region containing the bucket. | string | Required. |
| Service Endpoint | A custom service endpoint, when required. | string | Optional. |
| Bucket Name | The name of the bucket containing the object to delete. | string | Required. |
| Key | The object key (filename or path) of the object in S3. For nested objects, include the full path. For example, `folder/file.txt`. | string | Required. |

</TabItem>
<TabItem value="output" label="Output Parameters">

Returns the `status` of the deletion, the `bucket` name, and the object `key`.

</TabItem>
</Tabs>

## Create Folder

Creates an empty folder in an S3 bucket.

<Tabs>
<TabItem value="input" label="Input Parameters">

| Parameter | Description | Type | Required/Optional |
| --------- | ----------- | ---- | ----------------- |
| Region | The AWS region containing the bucket. | string | Required. |
| Service Endpoint | A custom service endpoint, when required. | string | Optional. |
| Bucket Name | The name of the bucket to create the folder in. | string | Required. |
| Folder Path | The path of the folder to create. For example, `documents/subfolder/`. A trailing `/` is added if you leave it out. | string | Required. |

</TabItem>
<TabItem value="output" label="Output Parameters">

Returns the `status` of the operation, the `bucket` name, and the `folderPath` of the created folder, including the trailing `/`.

</TabItem>
</Tabs>

## List Folders

Lists the folders in an S3 bucket, meaning the objects whose key ends with `/`. An object nested under a path with no folder marker is not listed as a folder.

<Tabs>
<TabItem value="input" label="Input Parameters">

| Parameter | Description | Type | Required/Optional |
| --------- | ----------- | ---- | ----------------- |
| Region | The AWS region containing the bucket. | string | Required. |
| Service Endpoint | A custom service endpoint, when required. | string | Optional. |
| Bucket Name | The name of the bucket to list folders from. | string | Required. |
| Max Folders | The maximum number of folders to return. Defaults to 1000. | integer | Optional. |

</TabItem>
<TabItem value="output" label="Output Parameters">

Returns a `folders` array, where each entry includes the folder `key`, `lastModified` timestamp, `etag`, `size`, `storageClass`, `checksumAlgorithm`, and `checksumType`.

</TabItem>
</Tabs>

## Delete Folder

Deletes a folder and all objects within it.

<Tabs>
<TabItem value="input" label="Input Parameters">

| Parameter | Description | Type | Required/Optional |
| --------- | ----------- | ---- | ----------------- |
| Region | The AWS region containing the bucket. | string | Required. |
| Service Endpoint | A custom service endpoint, when required. | string | Optional. |
| Bucket Name | The name of the bucket containing the folder to delete. | string | Required. |
| Folder Path | The path of the folder to delete. All contents within the folder will be removed. A trailing `/` is added if you leave it out. | string | Required. |

</TabItem>
<TabItem value="output" label="Output Parameters">

Returns the `status` of the deletion, the `bucket` name, the `folderPath`, the number of `deletedObjects`, and a `deletedKeys` array listing all deleted object keys. If the folder has no objects, it still returns `success` with `deletedObjects` as 0.

</TabItem>
</Tabs>
