# Google Slides Integration with Orkes Conductor

:::info Available since:
- v5.7.0 and later
:::

Integrating Google Slides with Orkes Conductor lets you build workflows that interact with your Google Slides using the following operations:

- Create Presentation
- Add Slide
- Add Text Box
- Get Presentation Slides
- Get Presentation
- Get Page
- Replace Text in Presentation
- Get Thumbnail

This guide explains how to set up and use the integration. Here’s an overview:

1. Get the required credentials from Google Console.
2. Configure a new Google Slides integration in Orkes Conductor.
3. Use Google Slides integration in workflows.

## Step 1: Get the Google Console credentials

To integrate Google Slides with Orkes Conductor, create a service account in Google Cloud Console, enable the required APIs, and download its JSON key.

**To get the service account:**

1. Go to the [Google Cloud Console](https://console.cloud.google.com/).
2. Select your project or create a new one.
3. Go to **IAM & Admin** > **Service Accounts**.
4. Select **+ Create service account**, enter a **Name**, and select **Create and continue** > **Done**.
5. Open the service account and go to the **Keys** tab.
6. Select **Add key** > **Create new key** > **JSON** > **Create**. The key file downloads to your computer.
7. Copy the `client_email` value from the JSON file.

**To enable the API access:**

1. Go to **APIs & Services** > **Enabled APIs & services**.
2. Select **+ Enable APIs and services**.
3. Enable **Google Slides API** and **Google Drive API**.

### Share the presentation with the service account

The service account can only access presentations that are shared with it. Use one of the following:

<ol>
<li><strong>Share a presentation.</strong> Share the Google Slides presentation with the <code>client_email</code> as <strong>Editor</strong>. Use <strong>Viewer</strong> if the workflow only reads presentations.
  <ol type="a">
  <li>In Google Drive, open the presentation and select <strong>Share</strong>.</li>
  <li>Enter the <code>client_email</code> (from the JSON file downloaded previously), set the role, and select <strong>Share</strong>.</li>
  </ol>
</li>
<li><strong>Add it to a Shared Drive.</strong> Add the <code>client_email</code> to the Shared Drive as <strong>Contributor</strong> or higher. Presentations in the drive are accessible.
  <ol type="a">
  <li>In Google Drive, open the Shared Drive and select <strong>Manage members</strong>.</li>
  <li>Enter the <code>client_email</code> (from the JSON file downloaded previously), set the role to <strong>Contributor</strong> or higher, and select <strong>Send</strong>.</li>
  </ol>
</li>
</ol>

[Create Presentation](/content/integrations/google-slides-operations#create-presentation) creates the presentation in a Shared Drive folder, so it requires the second option. With the **Commenter** or **Viewer** role, read operations succeed and write operations fail with a 403 permission error.

## Step 2: Add an integration for Google Slides

After obtaining the credentials, add a Google Slides integration to your Conductor cluster.

**To create an integration:**

<ol>
<li>Go to <strong>Integrations</strong> &gt; <strong>Connected Apps</strong> from the left navigation menu on your Conductor cluster.</li>
<li>Select <strong>+ New integration</strong>.</li>
<li>In the <strong>Productivity</strong> section, choose <strong>Google Slides</strong>.</li>
<li>Select <strong>+ Add</strong> and enter the following parameters:</li>
</ol>

| Parameter | Description | Required/Optional |
| --------- | ----------- | ----------------- |
| Integration name | A name for the integration. | Required. |
| Service Account JSON | Paste the full contents of the service account key JSON file downloaded in [Step 1](/content/integrations/google-slides#step-1-get-the-google-console-credentials). | Required. |
| Description | A description of the integration. | Required. |

<ol start="5">
<li>(Optional) Toggle the <strong>Active</strong> button off if you don't want to activate the integration instantly.</li>
<li>Select <strong>Save</strong>.</li>
</ol>

## Step 3: Use Google Slides integration in workflows

Once the integration is ready, this can be used directly within the workflows. 

**To use Google Slides integration in a workflow:**

<ol>
<li>Go to <strong>Definitions</strong> &gt; <strong>Workflow</strong> from the left navigation menu on your Conductor cluster.</li>
<li>Select <strong>+ Define workflow</strong>.</li>
<li>In your workflow, select the (<strong>+</strong>) icon and select <strong>Connected Apps</strong>.</li>
<li>In <strong>Add Task</strong> panel on the right, search for <strong>Google Slides</strong>, and select the integration created in <a href="/content/integrations/google-slides#step-2-add-an-integration-for-google-slides">Step 2</a>.</li>
</ol>

The following operations are available for use with this integration.

| Operation | Description |
| --------- | ----------- |
| [Create Presentation](/content/integrations/google-slides-operations#create-presentation) | Create a new Google Slides presentation in a Shared Drive, with the provided title. |
| [Add Slide](/content/integrations/google-slides-operations#add-slide) | Add a new slide with a predefined layout to a presentation. |
| [Add Text Box](/content/integrations/google-slides-operations#add-text-box) | Add a text box with content to a slide. |
| [Get Presentation Slides](/content/integrations/google-slides-operations#get-presentation-slides) | List the slide page IDs in a presentation. |
| [Get Presentation](/content/integrations/google-slides-operations#get-presentation) | Retrieve presentation metadata, including slides. |
| [Get Page](/content/integrations/google-slides-operations#get-page) | Fetch a single page (slide) by its object ID. |
| [Replace Text in Presentation](/content/integrations/google-slides-operations#replace-text-in-presentation) | Replace all occurrences of text in a presentation. |
| [Get Thumbnail](/content/integrations/google-slides-operations#get-thumbnail) | Fetch a page thumbnail URL. |

<ol start="5">
<li>Select the required operation, configure the parameters, and select <strong>Save</strong> &gt; <strong>Confirm</strong>.</li>
<li>Select <strong>Execute</strong> to run the workflow.</li>
</ol>

For the complete operations parameters and output reference, see [Google Slides Operations Reference](/content/integrations/google-slides-operations).
