# Google Docs Integration with Orkes Conductor

:::info Available since:
- v5.7.0 and later
:::

Integrating Google Docs with Orkes Conductor lets you build workflows that interact with your Google Docs using the following operations:

- Create Document
- Update Document
- Get Document
- Replace Text
- Append Text

This guide explains how to set up and use the integration. Here’s an overview:

1. Get the required credentials from Google Console.
2. Configure a new Google Docs integration in Orkes Conductor.
3. Use Google Docs integration in workflows.

## Step 1: Get the Google Console credentials

To integrate Google Docs with Orkes Conductor, create a service account in Google Cloud Console, enable the required APIs, and download its JSON key.

**To get the service account:**

1. Go to the [Google Cloud Console](https://console.cloud.google.com/).
2. Select your project or create a new one.
3. Go to **IAM & Admin** > **Service Accounts**.
4. Select **+ Create service account**, enter a **Name**, and select **Create and continue** > **Done**.
5. Open the service account and go to the **Keys** tab.
6. Select **Add key** > **Create new key** > **JSON** > **Create**. The key file downloads to your computer.
7. Copy the `client_email` value from the JSON file.

**To enable the API access:**

1. Go to **APIs & Services** > **Enabled APIs & services**.
2. Select **+ Enable APIs and services**.
3. Enable **Google Docs API** and **Google Drive API**.

### Share the docs with the service account

The service account can only access documents that are shared with it. Use one of the following:

<ol>
<li><strong>Share a document.</strong> Share the Google Doc with the <code>client_email</code> as <strong>Editor</strong>. Use <strong>Viewer</strong> if the workflow only reads documents.
  <ol type="a">
  <li>In Google Drive, open the document and select <strong>Share</strong>.</li>
  <li>Enter the <code>client_email</code> (from the JSON file downloaded previously), set the role, and select <strong>Share</strong>.</li>
  </ol>
</li>
<li><strong>Share a folder.</strong> Share a folder in My Drive with the <code>client_email</code> as <strong>Editor</strong>. Documents in the folder are accessible.
  <ol type="a">
  <li>In Google Drive, open the folder and select <strong>Share</strong>.</li>
  <li>Enter the <code>client_email</code> (from the JSON file downloaded previously), set the role, and select <strong>Share</strong>.</li>
  </ol>
</li>
<li><strong>Add it to a Shared Drive.</strong> Add the <code>client_email</code> to the Shared Drive as <strong>Content manager</strong> or higher. Documents in the drive are accessible.
  <ol type="a">
  <li>In Google Drive, open the Shared Drive and select <strong>Manage members</strong>.</li>
  <li>Enter the <code>client_email</code> (from the JSON file downloaded previously), set the role to <strong>Content manager</strong> or higher, and select <strong>Send</strong>.</li>
  </ol>
</li>
</ol>

The [Create Document](/content/integrations/google-docs-operations#create-document) operation works only with option 3, because documents can be created only in a Shared Drive.

## Step 2: Add an integration for Google Docs

After obtaining the credentials, add a Google Docs integration to your Conductor cluster.

**To create an integration:**

<ol>
<li>Go to <strong>Integrations</strong> &gt; <strong>Connected Apps</strong> from the left navigation menu on your Conductor cluster.</li>
<li>Select <strong>+ New integration</strong>.</li>
<li>In the <strong>Productivity</strong> section, choose <strong>Google Docs</strong>.</li>
<li>Select <strong>+ Add</strong> and enter the following parameters:</li>
</ol>

| Parameters | Description | Required/Optional |
| ---------- | ----------- | ----------------- |
| Integration name | A name for the integration. | Required. |
| Service Account JSON | Paste the full contents of the service account key JSON file downloaded in [Step 1](/content/integrations/google-docs#step-1-get-the-google-console-credentials). | Required. |
| Description | A description of the integration. | Required. |

<ol start="5">
<li>(Optional) Toggle the <strong>Active</strong> button off if you don’t want to activate the integration instantly.</li>
<li>Select <strong>Save</strong>.</li>
</ol>

## Step 3: Use Google Docs integration in workflows

Once the integration is ready, this can be used directly within the workflows.

**To use Google Docs integration in a workflow:**

<ol>
<li>Go to <strong>Definitions</strong> &gt; <strong>Workflow</strong> from the left navigation menu on your Conductor cluster.</li>
<li>Select <strong>+ Define workflow</strong>.</li>
<li>In your workflow, select the (<strong>+</strong>) icon and select <strong>Connected Apps</strong>.</li>
<li>In <strong>Add Task</strong> panel on the right, search for <strong>Google Docs</strong>, and select the integration created in <a href="/content/integrations/google-docs#step-2-add-an-integration-for-google-docs">Step 2</a>.</li>
</ol>

The following operations are available for use with this integration.

| Operations | Description |
| ---------- | ----------- |
| [Create Document](/content/integrations/google-docs-operations#create-document) | Create a new Google Doc in a Shared Drive, with a title and content. |
| [Update Document](/content/integrations/google-docs-operations#update-document) | Replace all document content with new text. |
| [Get Document](/content/integrations/google-docs-operations#get-document) | Fetch a Google Doc by ID, including structure and content metadata. |
| [Replace Text](/content/integrations/google-docs-operations#replace-text) | Find and replace all occurrences of target text in a Google Doc. |
| [Append Text](/content/integrations/google-docs-operations#append-text) | Append text to the end of an existing Google Doc. |

<ol start="5">
<li>Select the required operation, configure the parameters, and select <strong>Save</strong> &gt; <strong>Confirm</strong>.</li>
<li>Select <strong>Execute</strong> to run the workflow.</li>
</ol>

For the complete operations parameters and output reference, see [Google Docs Operations Reference](/content/integrations/google-docs-operations).
