# Google Drive Integration with Orkes Conductor

:::info Available since:
- v5.7.0 and later
:::

Integrating Google Drive with Orkes Conductor lets you build workflows that interact with your Drive files and folders using the following operations:

- Create Folder
- Delete Folder
- Share Folder
- Upload File from Base64
- Download File Base64
- Create File from Text
- Create Google Doc
- Copy File
- Update File
- Move File
- Share File
- List Files
- Delete File
- Search Files and Folders
- Update Shared Drive
- Get Shared Drive
- Get Many Shared Drives
- Delete Shared Drive

This guide explains how to set up and use the integration. Here’s an overview:

1. Get the required credentials from Google Console.
2. Configure a new Google Drive integration in Orkes Conductor.
3. Use Google Drive integration in workflows.

## Step 1: Get the Google Console credentials

To integrate Google Drive with Orkes Conductor, you need a Google Cloud service account and its JSON key file, with the Google Drive API enabled. You also need to share your Shared Drive with the service account.

**To create a service account and generate a key:**

1. Go to the [Google Cloud Console](https://console.cloud.google.com/) and select your project.
2. Navigate to **IAM & Admin** > **Service Accounts**.
3. Select **+ Create service account**, enter a name and description, and select **Create and close**. No IAM roles are needed, because access comes from sharing the Shared Drive.
4. Select the new service account, go to the **Keys** tab, and select **Add Key** > **Create new key**.
5. Choose **JSON** as the key type and select **Create**. The key file downloads automatically.

Keep the JSON file ready. You need its full contents in Step 2.

**To enable Google Drive API access:**

1. Go to **APIs & Services** > **Enabled APIs & services**.
2. Select **+ Enable APIs and services**.
3. Search for **Google Drive API** and enable it.

### Share the Shared Drive with the service account

The integration can only access Shared Drives that are shared with the service account. A folder in My Drive cannot be used as the parent folder.

1. Open **Google Drive**, go to **Shared drives**, and open the **Shared Drive**.
2. Select **Manage members**.
3. Enter the service account's email (the `client_email` value in the JSON key file), set the required role, and select **Send**.
    - The **Content manager** role is enough for all file and folder operations except deleting.
    - The **Manager** role is needed for **Delete File** and **Delete Folder** operations.
4. To get a folder ID, open the folder in the Shared Drive. The ID is the string at the end of the URL: `https://drive.google.com/drive/u/0/folders/<FOLDER-ID>`. You enter it in each operation that needs a parent folder.

## Step 2: Add an integration for Google Drive

After obtaining the credentials, add a Google Drive integration to your Conductor cluster.

**To create an integration:**

<ol>
<li>Go to <strong>Integrations</strong> &gt; <strong>Connected Apps</strong> from the left navigation menu on your Conductor cluster.</li>
<li>Select <strong>+ New integration</strong>.</li>
<li>In the <strong>Productivity</strong> section, choose <strong>Google Drive</strong>.</li>
<li>Select <strong>+ Add</strong> and enter the following parameters:</li>
</ol>

| Parameters | Description | Required/Optional |
| --------- | ----------- | ----------------- |
| Integration name | A name for the integration. | Required. |
| Service Account JSON | Paste the full contents of the service account key JSON file downloaded in [Step 1](/content/integrations/google-drive#step-1-get-the-google-console-credentials). | Required. |
| Description | A description of the integration. | Required. |

<ol start="5">
<li>(Optional) Toggle the <strong>Active</strong> button off if you don't want to activate the integration instantly.</li>
<li>Select <strong>Save</strong>.</li>
</ol>

## Step 3: Use Google Drive integration in workflows

Once the integration is ready, this can be used directly within the workflows.

**To use Google Drive integration in a workflow:**

<ol>
<li>Go to <strong>Definitions</strong> &gt; <strong>Workflow</strong> from the left navigation menu on your Conductor cluster.</li>
<li>Select <strong>+ Define workflow</strong>.</li>
<li>In your workflow, select the (<strong>+</strong>) icon and select <strong>Connected Apps</strong>.</li>
<li>In <strong>Add Task</strong> panel on the right, search for <strong>Google Drive</strong>, and select the integration created in <a href="/content/integrations/google-drive#step-2-add-an-integration-for-google-drive">Step 2</a>.</li>
</ol>

The following operations are available for use with this integration.

| Operations | Description |
| --------- | ----------- |
| [Create Folder](/content/integrations/google-drive-operations#create-folder) | Create a folder in a Shared Drive under a parent folder. |
| [Delete Folder](/content/integrations/google-drive-operations#delete-folder) | Delete a folder in Drive. |
| [Share Folder](/content/integrations/google-drive-operations#share-folder) | Share a folder with a user. |
| [Upload File From Base64](/content/integrations/google-drive-operations#upload-file-from-base64) | Upload a file from base64-encoded content into Google Drive. |
| [Download File Base64](/content/integrations/google-drive-operations#download-file-base64) | Download a file's content as base64 by file ID. |
| [Create File From Text](/content/integrations/google-drive-operations#create-file-from-text) | Create a new file in Drive from plain text content. |
| [Create Google Doc](/content/integrations/google-drive-operations#create-google-doc) | Create a Google Doc with a title and plain text content. |
| [Copy File](/content/integrations/google-drive-operations#copy-file) | Copy a file in Google Drive. |
| [Update File](/content/integrations/google-drive-operations#update-file) | Update a file's metadata or content. |
| [Move File](/content/integrations/google-drive-operations#move-file) | Move a file to another folder. |
| [Share File](/content/integrations/google-drive-operations#share-file) | Share a file with a user. |
| [List Files](/content/integrations/google-drive-operations#list-files) | Lists files from Google Drive matching the query. |
| [Delete File](/content/integrations/google-drive-operations#delete-file) | Delete a file by file ID. |
| [Search Files and Folders](/content/integrations/google-drive-operations#search-files-and-folders) | Search files and folders in Google Drive. |
| [Update Shared Drive](/content/integrations/google-drive-operations#update-shared-drive) | Update the name of a shared drive. |
| [Get Shared Drive](/content/integrations/google-drive-operations#get-shared-drive) | Retrieve a shared drive by ID. |
| [Get Many Shared Drives](/content/integrations/google-drive-operations#get-many-shared-drives) | List the shared drives the service account is a member of. |
| [Delete Shared Drive](/content/integrations/google-drive-operations#delete-shared-drive) | Delete a shared drive. |

<ol start="5">
<li>Select the required operation, configure the parameters, and select <strong>Save</strong> &gt; <strong>Confirm</strong>.</li>
<li>Select <strong>Execute</strong> to run the workflow.</li>
</ol>

For the complete operation parameters and output reference, see [Google Drive Operations Reference](/content/integrations/google-drive-operations).
