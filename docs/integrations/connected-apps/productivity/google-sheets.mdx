# Google Sheets Integration with Orkes Conductor

:::info Available since:
- v5.7.0 and later
:::

Integrating Google Sheets with Orkes Conductor lets you build workflows that interact with your Google Sheets using the following operations:

- Create Spreadsheet
- Delete Spreadsheet
- Append Values
- Append Row
- Append or Update Row
- Read Values
- Get Rows
- Update Row
- Clear Range
- Clear Sheet
- Create Sheet
- Delete Sheet
- Delete Rows or Columns

This guide explains how to set up and use the integration. Here’s an overview:

1. Get the required credentials from Google Console.
2. Configure a new Google Sheets integration in Orkes Conductor.
3. Use Google Sheets integration in workflows.

## Step 1: Get the Google Console credentials

To integrate Google Sheets with Orkes Conductor, create a service account in Google Cloud Console, enable the required APIs, and download its JSON key.

**To get the service account:**

1. Go to the [Google Cloud Console](https://console.cloud.google.com/).
2. Select your project or create a new one.
3. Go to **IAM & Admin** > **Service Accounts**.
4. Select **+ Create service account**, enter a **Name**, and select **Create and continue** > **Done**.
5. Open the service account and go to the **Keys** tab.
6. Select **Add key** > **Create new key** > **JSON** > **Create**. The key file downloads to your computer.
7. Copy the `client_email` value from the JSON file.

**To enable the API access:**

1. Go to **APIs & Services** > **Enabled APIs & services**.
2. Select **+ Enable APIs and services**.
3. Enable **Google Sheets API** and **Google Drive API**.

### Share the spreadsheet with the service account

The service account can only access spreadsheets that are shared with it. Use one of the following:

<ol>
<li><strong>Share a spreadsheet.</strong> Share the Google Sheet with the <code>client_email</code> as <strong>Editor</strong>. Use <strong>Viewer</strong> if the workflow only reads spreadsheets.
  <ol type="a">
  <li>In Google Drive, open the spreadsheet and select <strong>Share</strong>.</li>
  <li>Enter the <code>client_email</code> (from the JSON file downloaded previously), set the role, and select <strong>Share</strong>.</li>
  </ol>
</li>
<li><strong>Share a folder.</strong> Share a folder in My Drive with the <code>client_email</code> as <strong>Editor</strong>. Spreadsheets in the folder are accessible.
  <ol type="a">
  <li>In Google Drive, open the folder and select <strong>Share</strong>.</li>
  <li>Enter the <code>client_email</code> (from the JSON file downloaded previously), set the role, and select <strong>Share</strong>.</li>
  </ol>
</li>
<li><strong>Add it to a Shared Drive.</strong> Add the <code>client_email</code> to the Shared Drive as <strong>Content manager</strong> or higher. Spreadsheets in the drive are accessible.
  <ol type="a">
  <li>In Google Drive, open the Shared Drive and select <strong>Manage members</strong>.</li>
  <li>Enter the <code>client_email</code> (from the JSON file downloaded previously), set the role to <strong>Content manager</strong> or higher, and select <strong>Send</strong>.</li>
  <li>To delete spreadsheets, the service account must be a <strong>Manager</strong> of the Shared Drive. See <a href="/content/integrations/google-sheets-operations#delete-spreadsheet">Delete Spreadsheet</a>.</li>
  </ol>
</li>
</ol>

With **Viewer** access, read operations succeed and write operations fail with a 403 permission error.

## Step 2: Add an integration for Google Sheets

After obtaining the credentials, add a Google Sheets integration to your Conductor cluster.

**To create an integration:**

<ol>
<li>Go to <strong>Integrations</strong> &gt; <strong>Connected Apps</strong> from the left navigation menu on your Conductor cluster.</li>
<li>Select <strong>+ New integration</strong>.</li>
<li>In the <strong>Productivity</strong> section, choose <strong>Google Sheets</strong>.</li>
<li>Select <strong>+ Add</strong> and enter the following parameters:</li>
</ol>

| Parameters | Description | Required/Optional |
| --------- | ----------- | ----------------- |
| Integration name | A name for the integration. | Required. |
| Service Account JSON | Paste the full contents of the service account key JSON file downloaded in [Step 1](/content/integrations/google-sheets#step-1-get-the-google-console-credentials). | Required. |
| Description | A description of the integration. | Required. |

<ol start="5">
<li>(Optional) Toggle the <strong>Active</strong> button off if you don’t want to activate the integration instantly.</li>
<li>Select <strong>Save</strong>.</li>
</ol>

## Step 3: Use Google Sheets integration in workflows

Once the integration is ready, this can be used directly within the workflows.

**To use Google Sheets integration in a workflow:**

<ol>
<li>Go to <strong>Definitions</strong> &gt; <strong>Workflow</strong> from the left navigation menu on your Conductor cluster.</li>
<li>Select <strong>+ Define workflow</strong>.</li>
<li>In your workflow, select the (<strong>+</strong>) icon and select <strong>Connected Apps</strong>.</li>
<li>In <strong>Add Task</strong> panel on the right, search for <strong>Google Sheets</strong>, and select the integration created in <a href="/content/integrations/google-sheets#step-2-add-an-integration-for-google-sheets">Step 2</a>.</li>
</ol>

The following operations are available for use with this integration.

| Operations | Description |
| ---------- | ----------- |
| [Create Spreadsheet](/content/integrations/google-sheets-operations#create-spreadsheet) | Create a new Google Sheets spreadsheet in the Shared Drive with the provided title. |
| [Delete Spreadsheet](/content/integrations/google-sheets-operations#delete-spreadsheet) | Permanently delete a spreadsheet by its ID, without moving it to the trash. |
| [Append Values](/content/integrations/google-sheets-operations#append-values) | Append multiple rows to a specified range in a sheet. |
| [Append Row](/content/integrations/google-sheets-operations#append-row) | Append a single row to a sheet. |
| [Append or Update Row](/content/integrations/google-sheets-operations#append-or-update-row) | Update a row at the given index if it exists, or append a new row at the end of the sheet if it doesn't. |
| [Read Values](/content/integrations/google-sheets-operations#read-values) | Read values from a specified range in a sheet. |
| [Get Rows](/content/integrations/google-sheets-operations#get-rows) | Read all rows from a sheet. |
| [Update Row](/content/integrations/google-sheets-operations#update-row) | Update a specific row by index. |
| [Clear Range](/content/integrations/google-sheets-operations#clear-range) | Clear values from a specified range in a sheet. |
| [Clear Sheet](/content/integrations/google-sheets-operations#clear-sheet) | Clear all values from a sheet while keeping the sheet structure. |
| [Create Sheet](/content/integrations/google-sheets-operations#create-sheet) | Create a new sheet (tab) within a spreadsheet. |
| [Delete Sheet](/content/integrations/google-sheets-operations#delete-sheet) | Delete a sheet (tab) from a spreadsheet. |
| [Delete Rows or Columns](/content/integrations/google-sheets-operations#delete-rows-or-columns) | Delete a range of rows or columns from a sheet. |

<ol start="5">
<li>Select the required operation, configure the parameters, and select <strong>Save</strong> &gt; <strong>Confirm</strong>.</li>
<li>Select <strong>Execute</strong> to run the workflow.</li>
</ol>

For the complete operations parameters and output reference, see [Google Sheets Operations Reference](/content/integrations/google-sheets-operations).
