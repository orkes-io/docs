# Google Calendar Integration with Orkes Conductor

:::info Notes
- **Available since:** v5.7.0 and later
:::

Integrating Google Calendar with Orkes Conductor lets you build workflows that interact with your Google Calendar using the following operations:

- Add Event
- List Upcoming Events
- Update Event
- Update Event Time
- Get Event
- Check Availability
- Delete Event

This guide explains how to set up and use the integration. Here's an overview:

1. Get the required credentials from Google Cloud Console.
2. Configure a new Google Calendar integration in Orkes Conductor.
3. Use Google Calendar integration in workflows.

## Step 1: Get the Google Cloud credentials

To integrate Google Calendar with Orkes Conductor, you need a Google Cloud service account and its JSON key file, with the Google Calendar API enabled. You also need to share your calendar with the service account.

**To create a service account and generate a key:**

1. Go to the [Google Cloud Console](https://console.cloud.google.com/) and select your project.
2. Navigate to **IAM & Admin** > **Service Accounts**.
3. Select **+ Create service account**, enter a name and description, and select **Create and continue**.
4. Select **Continue**, then **Done**. No IAM roles are needed, because access comes from sharing the calendar.
5. Select the new service account, go to the **Keys** tab, and select **Add Key** > **Create new key**.
6. Choose **JSON** as the key type and select **Create**. The key file downloads automatically.

Keep the JSON file ready. You need its full contents in Step 2.

**To enable the Google Calendar API:**

1. Go to **APIs & Services** > **Enabled APIs & services**.
2. Select **+ Enable APIs and services**.
3. Search for **Google Calendar API** and enable it.

### Share the calendar with the service account

The integration can only access calendars that are shared with the service account.

1. Open **Google Calendar**, hover over the calendar, and select **⋮** > **Settings and sharing**.
2. Under **Share with specific people or groups**, select **+ Add people and groups**.
3. Enter the service account's email (the `client_email` value in the JSON key file), set the permission to **Make changes and see all event details**, and select **Send**.
4. Scroll to **Integrate calendar** and copy the **Calendar ID**. You enter it in each operation.

Read-only sharing (**See event details**) works only for the Get Event, Check Availability, and List Upcoming Events operations.

## Step 2: Add an integration for Google Calendar

After obtaining the credentials, add a Google Calendar integration to your Conductor cluster.

**To create an integration:**

<ol>
<li>Go to <strong>Integrations</strong> &gt; <strong>Connected Apps</strong> from the left navigation menu on your Conductor cluster.</li>
<li>Select <strong>+ New integration</strong>.</li>
<li>In the <strong>Productivity</strong> section, choose <strong>Google Calendar</strong>.</li>
<li>Select <strong>+ Add</strong> and enter the following parameters:</li>
</ol>

| Parameter | Description | Required/Optional |
| --------- | ----------- | ----------------- |
| Integration name | A name for the integration. | Required. |
| Service Account JSON | Paste the full contents of the service account key JSON file downloaded in [Step 1](/content/integrations/google-calendar#step-1-get-the-google-cloud-credentials). | Required. |
| Description | A description of the integration. | Required. |

<ol start="5">
<li>(Optional) Toggle the <strong>Active</strong> button off if you don't want to activate the integration instantly.</li>
<li>Select <strong>Save</strong>.</li>
</ol>

## Step 3: Use Google Calendar integration in workflows

Once the integration is ready, this can be used directly within the workflows.

**To use Google Calendar integration in a workflow:**

<ol>
<li>Go to <strong>Definitions</strong> &gt; <strong>Workflow</strong> from the left navigation menu on your Conductor cluster.</li>
<li>Select <strong>+ Define workflow</strong>.</li>
<li>In your workflow, select the (<strong>+</strong>) icon and select <strong>Connected Apps</strong>.</li>
<li>In <strong>Add Task</strong> panel on the right, search for <strong>Google Calendar</strong>, and select the integration created in <a href="/content/integrations/google-calendar#step-2-add-an-integration-for-google-calendar">Step 2</a>.</li>
</ol>

The following operations are available for use with this integration.

| Operation | Description |
| --------- | ----------- |
| [Add Event](/content/integrations/google-calendar-operations#add-event) | Create a new event in a Google Calendar with details including title, description, location, and time. |
| [List Upcoming Events](/content/integrations/google-calendar-operations#list-upcoming-events) | Retrieve a list of upcoming events from a Google Calendar within a specified time range. |
| [Update Event](/content/integrations/google-calendar-operations#update-event) | Update an existing event with details including title, description, location, and time. |
| [Update Event Time](/content/integrations/google-calendar-operations#update-event-time) | Update the start and end times of an existing calendar event by its event ID. |
| [Get Event](/content/integrations/google-calendar-operations#get-event) | Retrieve a calendar event by its unique event ID. |
| [Check Availability](/content/integrations/google-calendar-operations#check-availability) | Check calendar availability for a time slot. |
| [Delete Event](/content/integrations/google-calendar-operations#delete-event) | Delete a calendar event by its unique event ID. |

<ol start="5">
<li>Select the required operation, configure the parameters, and select <strong>Save</strong> &gt; <strong>Confirm</strong>.</li>
<li>Select <strong>Execute</strong> to run the workflow.</li>
</ol>

For the complete operations parameters and output reference, see [Google Calendar Operations Reference](/content/integrations/google-calendar-operations).
