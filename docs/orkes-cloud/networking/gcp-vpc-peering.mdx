# Connect Conductor Cluster with GCP VPC Peering

GCP VPC Peering sets up a single, **two-way private connection** between your network and your Conductor cluster, so traffic can flow in both directions over the same connection. This differs from GCP Private Service Connect, which requires a separate one-way connection for each direction you need.

## Prerequisites

- An Orkes-hosted GCP cluster

## Set up VPC Peering

### Share your cluster's details

1. Give Orkes the following details about your Conductor cluster:
    - **Conductor Cluster** name
    - **Region**
    - **Zones**
    - **CIDR**
    - **GCP Project ID**
    - **VPC Network Name**

Orkes sets up the peering connection and shares the setup details with you.

### Complete setup on your end

Once Orkes shares its setup details, create the peering on your side.

1. In your GCP console, follow [Google's instructions for creating a VPC Network Peering](https://docs.cloud.google.com/vpc/docs/using-vpc-peering#creating_a_peering_configuration).
2. In the **Peered VPC network** section, select **In another project**, and enter the project ID and VPC network name Orkes shared with you.

Once both sides are set up, the **Status** column on the **VPC Network Peering** page shows the connection as active.
